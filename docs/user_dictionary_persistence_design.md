# TAB5 SKK ユーザー辞書の学習・保存方式

## 用語

本書では、候補選択により優先順を変える処理を**学習**、RAM上の未保存の学習結果を**保留中の学習**、SPIFFSの`userdict`パーティションへ反映する処理を**Flash保存**と呼ぶ。

## 学習設定

| 設定名 | 候補確定時の学習 | Flashへの自動保存 | Flash保存の契機 |
|:---|:---:|:---:|:---|
| Off（学習しない） | 行わない | 行わない | 自動学習由来では行わない |
| 保留保存 | 行う | 行う | 60秒の無操作時、または16件の保留変更時 |
| 手動保存 | 行う | 行わない | Save Learning操作時だけ |

`Off`は、候補を確定しても候補順を変えない。`手動保存`は候補順をRAM上で即時に変えるが、保存操作または電源断前に保存しなければ、その起動中の保留学習は失われる。

## 手動操作とFlash・SDの扱い

| 操作 | Flash | SDの`/TAB5-SKK/SKKUSER.TXT` | 備考 |
|:---|:---:|:---:|:---|
| Save Learning | 保存 | 保存 | 保留学習をFlashへ反映後、完全なFlash辞書をSDへバックアップする。 |
| Dictionary EditorのAdd / Promote | 保存 | 保存 | 手動登録後の完全なユーザー辞書をSDへバックアップする。 |
| Dictionary EditorのDelete Exact | 保存 | 保存 | 手動削除後の完全なユーザー辞書をSDへバックアップする。 |
| Import Merge / Replace | 保存 | 保存 | インポート後の最終辞書をSDへ再出力して正規化する。 |
| Export SD | 保存しない | 保存 | Flash上の保存済み辞書を読出してSDへ出力するだけ。 |

## SDバックアップ失敗時の方針

SPIFFSとmicroSDをまたぐ完全な原子トランザクションは実現できない。Flashを主データ、SDをバックアップと位置付ける。

1. 手動操作は、まずFlashへ安全に保存する。
2. 成功後、同じ完全辞書をSDへエクスポートする。
3. SD未挿入・書込み失敗の場合、Flash保存は取り消さない。
4. 画面に`Learning saved to Flash; SD backup failed`など、Flash保存済みでSDバックアップだけ失敗したことを表示する。
5. 次の手動保存またはExport SDの成功時に、Flashの完全辞書でSDバックアップを更新する。

この順序は、SDカードの抜去・書込み禁止で手動登録や学習保存が不能になることを避けつつ、SDバックアップの遅延を明示する。

## Flash耐久性

手動保存では、全量更新の頻度は利用者の明示操作に限定される。候補確定ごとの書込みは行わない。Dictionary Editorによる登録・削除も明示的な低頻度操作として扱う。ただし、同じ操作を反復すればFlash書込みが増えるため、寿命を数値保証するものではない。
