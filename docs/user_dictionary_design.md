# TAB5 SKK ユーザー辞書・補助辞書設計

**作成者:** Manus AI
**対象ブランチ:** `feature/local-japanese-ime`

## 目的

TAB5版SKKは小規模な`SKK-JISYO.S`をシステム辞書として使う。このため、標準SKK辞書にはあるが小辞書にはない「来た」のような語、固有名詞、技術用語を利用者が補える必要がある。本設計では、Flashへ同梱する補助辞書と、実行時に更新するユーザー辞書を分ける。

| 辞書 | 配置 | 更新方法 | 検索優先度 | 主用途 |
|:---|:---|:---|:---:|:---|
| ユーザー辞書 | `userdict` SPIFFS、`/skk-user/SKK-JISYO.user.txt` | 設定可能な候補学習、辞書編集画面 | 1 | 個人の候補順、登録語 |
| 補助辞書 | `skk` SPIFFS、`/skk/SKK-JISYO.TAB5.txt` | ソース資産を更新して再ビルド・フラッシュ | 2 | 小辞書欠落の共通語 |
| システム辞書 | `skk` SPIFFS、`/skk/SKK-JISYO.S.txt` | プロジェクト同梱 | 3 | 基本語彙 |

候補は優先順位の高い辞書から順に追加し、同一候補は重複表示しない。各辞書はUTF-8、LF改行、標準SKKの`読み /候補1/候補2/`形式を使用する。

## 辞書編集画面

`Ctrl+Alt+D`でTAB5ローカルの**Dictionary Editor**を開く。画面を開いた間は、キーボード入力と辞書操作は接続先へ送らない。編集画面は以下の3フィールドを持つ。

| フィールド | 入力内容 | 入力方法 |
|:---|:---|:---|
| Reading | 見出し語のひらがな読み | 小文字ローマ字で入力し、`Ctrl+J`でフィールドへ確定 |
| Okuri | 送り仮名の先頭となるASCII英字、不要なら空欄 | 英字を直接入力 |
| Candidate | 登録・削除するUTF-8候補文字列 | TAB5の既存SKKで候補選択して`Ctrl+J`でフィールドへ確定、またはキーボードが渡すUTF-8を直接入力 |

Tabでフィールドを移動する。Backspaceは、IMEに未確定文字列があればIME編集を優先し、未確定文字列がなければ選択中フィールド末尾を削除する。Editor下部には、現在の確定先フィールドを示す`IME -> ...`行、未確定かな、候補選択中の候補一覧を表示する。これにより、`Ctrl+J`でフィールドへ格納する前の入力内容を常に確認できる。

| 操作 | 動作 |
|:---|:---|
| `Ctrl+Alt+D` | 編集画面を開く／閉じる。閉じる場合は未保存のフィールドを破棄する。 |
| Tab | 次の編集フィールドへ移動する。 |
| `Ctrl+J` | 現在のIME未確定文字列または候補を選択中フィールドへ確定する。CRは送らない。 |
| `Ctrl+S` | `Reading + Okuri`をキー、`Candidate`を候補としてユーザー辞書へ追加・先頭優先化する。Flash保存後にmicroSDへバックアップする。 |
| `Ctrl+X` | 指定したキーから完全一致する`Candidate`だけをユーザー辞書から削除する。キーに他候補が残れば維持し、最後の候補なら行を削除する。Flash保存後にmicroSDへバックアップする。 |
| `Ctrl+W` | 保留中の候補学習をFlashへ保存し、保存後の完全辞書をmicroSDへバックアップする。 |
| `Ctrl+E` | SPIFFSのユーザー辞書をmicroSDの`/TAB5-SKK/SKKUSER.TXT`へエクスポートする。 |
| `Ctrl+I` | microSDの交換ファイルを既存ユーザー辞書へマージする。既存候補順を維持し、重複候補は追加しない。 |
| `Ctrl+R` | 1回目は置換インポートの確認を表示し、2回目でmicroSDの交換ファイルによる置換を実行する。 |
| Esc | IME未確定文字列を取り消す。未確定文字列がなければ画面を閉じる。 |

登録・削除に成功した場合はフィールドを保持し、結果メッセージを画面に表示する。空のReadingまたはCandidateによる操作は拒否する。OkuriはASCII英字1文字だけ許可する。候補確定時の学習保存は、設定画面で学習しない・保留保存・手動保存を選べる。手動保存では候補順位をRAMへ直ちに反映するが、`Ctrl+W`またはSave LearningまでFlashへは書き込まない。

## 例: 「来た」を登録する

小辞書に`きt /来/`がない場合、補助辞書が未導入でも手動登録できる。Dictionary EditorでReadingへ`ki`を入力して`Ctrl+J`、Okuriへ`t`を入力し、Candidateへ既存の`くr /来/`候補から「来」を選んで`Ctrl+J`で確定し、**Ctrlを押したままS**を押す。以後は通常の`KiTa`→Space→Enterで「来た」を変換できる。

## 補助辞書の初期内容とライセンス

`SKK-JISYO.TAB5.txt`は本プロジェクトが作成する小さな補助辞書であり、初期状態では小辞書で不足する標準SKKの基本活用キーを収録する。外部のSKK辞書データを転記・追加する場合は、元辞書のライセンスを同梱して出典を記録する。利用者固有の登録語はユーザー辞書にだけ保存し、ビルド時の`skk`イメージ更新で上書きしない。

## microSD辞書入出力

Tab5のmicroSDをFAT32で初期化し、Dictionary Editorを開いた状態で操作する。エクスポートは`/TAB5-SKK/SKKUSER.TXT`を8.3形式の一時・バックアップファイル経由で公開する。FATFSで既存のファイルをリネーム上書きできないため、既存ファイルを退避してから新しいファイルを公開する。インポートはUTF-8/LFのSKK行形式、候補区切り、1行の最大長を検証してから実行する。形式不正のファイルはSPIFFS上の学習辞書を変更しない。

マージは既存候補の順序を保ち、SDカード由来の候補だけを末尾へ追加する安全な既定操作である。置換はユーザー辞書全体をSDカードの有効な内容へ差し替えるため、画面または`Ctrl+R`で2回連続して要求した場合だけ実行する。インポート、登録、削除、Save LearningはFlash保存後に完全辞書をmicroSDへバックアップする。SD未挿入、FATマウント失敗、ファイル不在、読み書きエラー、形式不正は画面の状態欄へ表示する。SDバックアップ失敗時も、成功済みのFlash保存は取り消さない。

## 非対象

辞書全件の一覧閲覧・検索、候補注釈の編集、複数端末との自動同期、外部辞書サーバは対象にしない。ユーザー辞書交換ファイルはSKKテキスト形式のため、PC上で編集してからmicroSD経由で取り込める。
