# 「来た」変換の調査結果

**対象:** `feature/local-japanese-ime` の同梱 `SKK-JISYO.S.txt` と現行IMEコア

## 訂正：一般的なSKKでの正しい入力

**一般的なSKKで「来た」を入力する正しいキー列は `KiTa`** である。語頭の`K`で見出し語「き」を開始し、`T`で送り仮名「た」の開始を指定する。標準の`SKK-JISYO.L`には `きt /来/切/着/.../` が登録されているため、候補「来」を選択すれば「来た」を確定できる。

先行版の本メモで`KuTa`とした説明は誤りだった。`くr /来/.../`は「来る」に対応するキーであり、過去形「来た」の読み「きた」には使用しない。

当初のTAB5実装では、同梱の小辞書に`きt`がなかったため、正しい`KiTa`を入力しても「来た」にならなかった。これは候補数上限ではなく、辞書資産の不足が直接原因だった。現在は補助辞書`SKK-JISYO.TAB5.txt`へ`きt /来/`を収録し、ユーザー辞書・補助辞書・小辞書の優先検索を実装しているため、`KiTa`→Space→Enterで「来た」を変換できる。

| 項目 | 標準SKK | 現行TAB5同梱辞書 |
|:---|:---|:---|
| 「来た」の正しい入力 | `KiTa` | 同じ |
| 必要な辞書キー | `きt /来/.../` | 補助辞書に`きt /来/`を収録 |
| `KiTa`後の候補 | — | 「来」を提示し、「来た」を確定 |
| 「来る」のキー | `くr /来/.../` | `くr /来/繰/暮/食/` |
| 結論 | `きt`で直接候補化 | 補助辞書で標準SKK入力を利用可能にした |

## 実機相当のIMEコア再現

補助辞書追加前の同梱小辞書だけでの再現結果は次のとおりであった。

| 入力 | オーバーレイ | Space後の候補 |
|:---|:---|:---|
| `KiTa` | `き / た` | 気、記、期、機…（同梱辞書に`きt`がないため「来」はない） |
| `KuTa` | `く / た` | 喰、朽（「来た」の入力ではない） |
| `KuRu` | `く / る` | 来、繰、暮、食 |

`KuRu`では「来る」を変換できるが、後から「た」へ活用させることはできない。小辞書単体には`きt`がないため、補助辞書を導入する前は正しいSKK入力である`KiTa`を使っても「来た」を直接入力する実用的な手順はなかった。

## 実装済みの修正

標準辞書の`きt /来/.../`を最小限の補助辞書`SKK-JISYO.TAB5.txt`へ反映した。これにより`KiTa`が直接「来た」を候補化できる。補助辞書は書換え可能なユーザー辞書より後、同梱小辞書より前に検索するため、利用者が登録した候補が優先される。

加えて、Dictionary Editorから同じキーと候補をユーザー辞書へ手動登録・削除できる。したがって、補助辞書に入っていない小辞書欠落語も、標準SKK形式のキーで個別に補える。
