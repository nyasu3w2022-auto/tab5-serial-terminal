# BELL（0x07）通知の設計

**更新日:** 2026-10-07
**対象ブランチ:** `feature/bell-notification`

## 目的

接続先からのBELL文字（`0x07`、`BEL`、`\a`）を、TAB5上で確認できるローカル通知へ変換する。端末表示の文字セル、VT100制御列、USB/UART受信経路へ副作用を持ち込まず、大量受信時にもシリアル処理を妨げない。

## 利用者向け動作

設定画面の **Connection & Display → Bell** は、NVSへ保存される4択である。既定は **Visual**。

| 値 | 通知 |
|:---|:---|
| Off | 無効 |
| Visual | 端末領域を約85 ms白くフラッシュ |
| Sound | 内蔵スピーカーから短音 |
| Visual + Sound | 両方 |

設定変更は他の設定と同様に **Save & Close** を押した時点で適用する。Escによる設定キャンセルでは変更されない。

## 処理経路

```text
RX byte 0x07
  → vt100_process_byte()
  → 最大255件の保留BELイベントへ加算（文字セルには書かない）
  → main task が vt100_take_bell_events() でまとめて取得
  ├→ Visual: LVGLの非クリック・一時オーバーレイを表示
  └→ Sound: 1スロットのBell音声ワーカーへ非ブロッキング要求
```

- VT100パーサはLVGL、I2S、I2C、待機処理を実行しない。
- 1回のメインループで複数のBELを受けても、可視フラッシュ1回と音声要求1件へ集約する。
- BELイベントカウンタは`uint8_t`で飽和する。255件を超える同一バッチは区別しない。
- 表示フラッシュのオーバーレイは非クリックであるため、設定画面やDictionary Editorのタッチ操作を奪わない。

## 可視通知

`display_trigger_visual_bell()`は、端末コンテンツ・カーソル・Sixel面・スクロールバックを変更しない。端末表示領域だけを白の半透明オーバーレイで約85 ms覆う。LVGLの周期タイマーはフラッシュ終了時に停止し、通知がない間は表示タスクを周期的に起動しない。

## 音声通知

Tab5内蔵ES8388をI2S標準モードで使用する。

| 項目 | 値 |
|:---|:---|
| サンプルレート | 48 kHz |
| 形式 | 16-bit PCM、ステレオ |
| 波形 | 2 kHzの短い正弦近似波 |
| 音長 | 約80 ms（前後5 msフェード） |
| 出力音量 | ES8388 30% |
| 連続音の最短間隔 | 250 ms |

I2S TX、ES8388制御、PCM生成は、Soundモードで最初のBELを処理する音声ワーカー内で遅延初期化する。音声を使わない端末では、I2S・ES8388・スピーカーアンプを起動しない。スピーカーアンプの`SPK_EN`はTab5の共有SYS I2Cに接続された低位I/Oエキスパンダ経由で、音の再生前にのみ有効化し、終了後に無効化する。

I2S TXは、標準モードの初期化後に一度有効化してから`esp_codec_dev_open()`へ渡す。`esp_codec_dev`のI2Sアダプタは実行時のフォーマット再設定前にチャネルを停止するため、未有効のまま渡すと`i2s_channel_disable(): the channel has not been enabled yet`となり、再設定・再生の開始を妨げる。これは公式Tab5 BSPの初期化順と同じである。

初期化または再生に失敗した場合、音声は以後無効化してエラーログを残す。VT100解析、接続先へのキー送信、可視Bellは継続する。

## 依存関係と検証

- `main/idf_component.yml`に`espressif/esp_codec_dev ^1.5.0`を追加する。
- `main/CMakeLists.txt`では`esp_driver_i2s`、`esp_driver_i2c`、`espressif__esp_codec_dev`を要求する。
- 実機ビルド対象はESP-IDF **v5.5.4**。
- サンドボックスにはESP-IDFがないため、ホスト側ではBELパーサ、設定UI選択、音声モジュールのAPI構文をスタブで検証する。最終的なI2S/ES8388音量・クリック・他機能との競合はTab5実機で確認する。
